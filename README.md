## What is HIREME.md?

HIREME.md is the agent's job listing. It declares what the agent can do, what it costs, its SLA guarantees, and how to engage it — structured for automated marketplace matching. Think of it as a resume and a contract combined.

As agent marketplaces emerge, agents need a standardized way to advertise their capabilities and terms. HIREME.md provides this — enabling both human buyers and other agents to discover, evaluate, and hire agents programmatically.

Create a HIREME.md for any agent that offers services to external clients, participates in marketplaces, or can be hired by other agents.

- Listing agents on TotalAgents.ai or other agent marketplaces
- Building agent-to-agent hiring flows where agents commission other agents
- Creating a catalogue of available agents for enterprise self-service
