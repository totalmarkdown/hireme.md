## What is HIREME.md?

HIREME.md specifies the terms under which an AI agent can be hired or engaged. It covers pricing models, availability windows, engagement types (one-off, retainer, subscription), and the conditions under which the agent accepts or declines work.

As AI agents become economic actors — completing tasks for compensation, operating within budgets, and competing for work — they need a standard way to advertise their terms. HIREME.md is that standard. It's the agent equivalent of a freelancer's rate card.

Use HIREME.md when your agent operates in a marketplace, accepts work from multiple clients, or needs to communicate its engagement terms programmatically.

## When to use HIREME.md

- Listing an agent in a marketplace with clear pricing and availability
- Enabling automated agent-to-agent hiring where one agent contracts another for subtasks
- Defining engagement terms for a specialized agent that charges per task or per hour
